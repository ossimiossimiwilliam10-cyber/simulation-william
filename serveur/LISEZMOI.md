# Rapports d'équipe

Ce dossier centralise tous les rapports demandés aux différents pôles de l'entreprise (RH, Technique, Commercial, Conformité, Direction).
L'objectif est d'avoir un historique visuel et persistant des évaluations, budgets, bilans d'activité, etc.

## Arborescence
- `rh/` : Rapports sur les équipes, salaires, contrats, évaluations.
- `technique/` : Suivi des chantiers, devis fournisseurs (Abdoul, Yves).
- `commercial/` : Suivi des prospects, contrats signés (Grace).
- `conformite/` : Risques, juridique (Esther, Aïcha).
- `direction/` : Synthèses générales (Aïcha).

## Règle d'usage
L'agent doit sauvegarder ici les livrables importants de l'équipe (format `.md` ou `.csv`) pour éviter qu'ils ne se perdent dans le journal quotidien.
L'agent doit lire ce dossier si le contexte nécessite des informations sur l'avancement d'un pôle.
