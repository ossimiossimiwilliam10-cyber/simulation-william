# Comment utiliser ce dossier

1. Copie le dossier `simulation-william/` sur ton PC.
2. **Claude Code** : ouvre un terminal dans ce dossier et lance `claude`.
   Le fichier `CLAUDE.md` est lu automatiquement.
   **Gemini CLI** : lance `gemini` dans ce dossier ; il lit `GEMINI.md`.
   (Les deux fichiers ont le même contenu : garde-les synchronisés si tu
   modifies les règles.)
3. Premier message conseillé :
   « Lis CLAUDE.md, tous les fichiers d'état et le dernier journal, puis
   reprends la simulation au point de reprise. »
4. Conseillé : `git init` dans le dossier, pour garder l'historique de
   chaque journée simulée.
